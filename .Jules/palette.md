## 2025-02-12 - Missing Skip Link in Next.js App Router
**Learning:** In Next.js App Router projects where `Header` components are included per-page (inside `main` or `body`) rather than globally in `layout.tsx`, implementing a global "Skip to Content" link requires careful coordination. The `SkipLink` component in `layout.tsx` must target an ID (`main-content`) that exists on *every* page. Since pages control their own markup, this ID must be manually added to the primary content container (often the first semantic element after the Header) in each page file. Additionally, `tabIndex={-1}` and `focus:outline-none` are essential on the target container to ensure programmatic focus works correctly without visual clutter, while maintaining accessibility.
**Action:** When working with decentralized layouts, always audit page templates to ensure a consistent `id="main-content"` target exists for global accessibility tools.
