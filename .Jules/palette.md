## 2025-02-17 - Missing Skip Link & Component Definition Issues
**Learning:** Accessibility features like "Skip to Content" links are often missed in visual-heavy portfolios but are critical for keyboard navigation. Additionally, defining React components inside render functions causes state reset issues and performance problems, which is caught by modern linters.
**Action:** Always verify keyboard navigation (Tab key) on visual-heavy sites and move helper components outside the main component function.
